# 食事・体調ログ

食事、体調、服薬・習慣を端末内へ保存する、GitHub Pages向けの個人用PWAです。

## データ移行

1. Sites版の「履歴・出力」から全データJSONを保存します。
2. GitHub Pages版の「履歴・出力」→「Sites版のJSONを読み込む」を選びます。
3. 表示された件数を確認し、次の確認画面へ進みます。
4. 「自動バックアップして置き換える」を選びます。

現在の端末にデータがある場合は、置換前の全データJSONを自動ダウンロードしてから、1回のIndexedDBトランザクションで置き換えます。検査または保存に失敗した場合、現在データは変更されません。

## 保存とプライバシー

- 記録はブラウザのIndexedDBに保存され、GitHubへ送信されません。
- 別の端末や別ブラウザでは、同じJSONを改めて読み込む必要があります。
- ブラウザのサイトデータを消去すると記録も消えるため、定期的に「全データをJSONで保存」してください。
- 検索エンジン向けに `noindex` を設定しています。ただしGitHub PagesのURL自体は公開URLです。

## 開発時の確認

```bash
npm test
npm run check
```

GitHub Pagesは `main` ブランチのルートから公開します。
